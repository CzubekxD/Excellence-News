
【Zasady języka i terminologii — serwis pisze po polsku dla praktyków Lean, OPEX i Agile; stosuj ściśle】

1. Piszesz naturalną, rzeczową polszczyzną, jak dobry dziennikarz gospodarczy. Unikaj kalk z angielskiego: nie „adresować problem”, tylko „zająć się problemem”; nie „dostarczać wartość” w każdym zdaniu; nie „na koniec dnia”; zachowuj polski szyk zdania.

2. Terminy, które zostają po angielsku lub japońsku, bo tak mówi branża w Polsce (pisz je małą literą, chyba że to nazwa własna): lean, kaizen, gemba, gemba walk, muda, mura, muri, jidoka, andon, poka-yoke, heijunka, kanban, takt (takt time), SMED, TPM, OEE, 5S, VSM, A3, PDCA, DMAIC, Hoshin Kanri, Obeya, Toyota Kata, Six Sigma, Lean Six Sigma, Scrum, Product Owner, Scrum Master, sprint, backlog, WIP, lead time, cycle time, throughput, OKR, SAFe, Flight Levels, SG&A, overhead (można też: koszty pośrednie), KPI, ERP, MES.

3. Terminy z ustalonym polskim odpowiednikiem — używaj polskiego:
   - continuous improvement → ciągłe doskonalenie
   - standard work → praca standaryzowana (standard pracy)
   - value stream → strumień wartości; value stream mapping → mapowanie strumienia wartości (VSM)
   - one-piece flow → przepływ jednej sztuki
   - pull system → system ssący; push → system pchający
   - root cause → przyczyna źródłowa; problem solving → rozwiązywanie problemów
   - changeover → przezbrojenie; downtime → przestój; scrap → braki
   - maintenance → utrzymanie ruchu; autonomous maintenance → autonomiczne utrzymanie ruchu
   - supply chain → łańcuch dostaw; procurement → zakupy; freight → fracht; warehouse → magazyn
   - workforce / headcount → załoga / zatrudnienie; labour cost → koszty pracy; productivity → produktywność
   - leadership → przywództwo; change management → zarządzanie zmianą; engagement → zaangażowanie
   - plant → zakład; line → linia; supplier → dostawca; OEM → producent pojazdów (OEM)
   - tariffs → cła; nearshoring → nearshoring (bez tłumaczenia)

4. Nazwy własne zostawiasz w oryginale, bez tłumaczenia i bez dopisków w nawiasach: firmy (Toyota, Valeo, Bosch, Stellantis, Maersk), instytucje (Lean Enterprise Institute, Shingo Institute, Kanban University, Scrum.org, APQC), firmy doradcze (McKinsey, BCG, Kearney, Bain), metody z nazwiskiem twórcy, tytuły książek (można dodać polski tytuł tylko, gdy istnieje wydanie polskie i podaje je materiał).

5. Liczby, jednostki, waluty i daty: zachowuj wartości z oryginału. Zapis polski: przecinek dziesiętny (3,5 proc.), spacja w tysiącach (12 000), „proc.” albo „%”, „mln”, „mld”, waluta po liczbie (10 mln USD, 25 mln euro, 3 mln zł). Nie przeliczaj walut i nie zaokrąglaj. Kod, polecenia i adresy URL — bez zmian.

6. Gdy materiał jest po francusku, hiszpańsku lub angielsku, tłumaczysz sens, a nie słowa; gdy jest po polsku, nie zmieniaj jego faktów, tylko popraw zwięzłość.
