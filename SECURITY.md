# Zgłaszanie problemów bezpieczeństwa

Jeśli znajdziesz obejście uprawnień, wyciek klucza, wstrzyknięcie kodu albo inny problem, który może zagrozić wdrożeniu, zgłoś go prywatnie przez [GitHub Security Advisories](https://github.com/CzubekxD/Excellence-News/security/advisories/new).

Podaj:

- wersję (commit) i sposób wdrożenia;
- najkrótsze kroki odtworzenia problemu w środowisku, które wolno ci testować;
- możliwe skutki, logi lub zrzuty ekranu bez danych wrażliwych.

Nie ujawniaj szczegółów podatności w publicznych zgłoszeniach i nie wysyłaj prawdziwych kluczy, haseł ani danych użytkowników. Problemy dotyczące samego frameworka warto zgłosić także w projekcie [AIHOT](https://github.com/KKKKhazix/AIHOT/security/advisories/new).
